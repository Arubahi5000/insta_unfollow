# insta_unfollow

A script to unfollow people on Instagram who don't follow you back.

## Overview

This project provides a script to help users automate the process of unfollowing Instagram accounts that do not follow them back. Its main purpose is to help manage your "following" list and maintain only mutual connections.

## Features

- Automatically identifies users not following you back
- Unfollows users efficiently
- Simple and easy to use

## Usage

Clone the repository and follow the instructions in the main script to get started.
